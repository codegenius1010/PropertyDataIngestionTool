🚀 HOW TO GET STARTED
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Read Documentation
   👉 Open: INDEX.md (quick navigation guide)
   👉 Or: QUICKSTART.md (5-minute setup)

STEP 2: Install Dependencies
   Command:  npm install && cd client && npm install && cd ..

STEP 3: Setup Database
   Command:  mysql -u root -p < server/config/schema.sql

STEP 4: Configure Environment
   Edit: .env file with your database credentials

STEP 5: Start Development
   Terminal 1:  npm run dev          (Backend on port 5000)
   Terminal 2:  npm run client       (Frontend on port 3000)

STEP 6: Open in Browser
   URL: http://localhost:3000

STEP 7: Test Upload
   Upload: SAMPLE_DATA.csv (10 test properties)
